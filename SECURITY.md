# Security

Report a vulnerability in private. Open a GitHub security advisory:

https://github.com/hushid/hushid/security/advisories/new

Do not open a public issue for a vulnerability. A public issue is a disclosure before a fix exists.

We acknowledge a report within 3 days. We aim to ship a fix, or a mitigation, within 90 days of confirming the report. The advisory says when that fix is released.
