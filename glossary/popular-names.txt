# Optional hushid glossary of popular given names and surnames.
# One entry per line. Blank lines and lines starting with # are ignored.
# A match uses the case on the line and a word boundary.
# The same letters with every accent left off match too.
# A different accent does not match.
# A capitalized word that is also an ordinary word is still matched.
#
# United States given names: Social Security Administration, top 100
# boy names and top 100 girl names among births in 1926-2025.
# https://www.ssa.gov/oact/babynames/decades/century.html
# United States surnames: Census Bureau, 2010 Census, top 100.
# https://www2.census.gov/topics/genealogy/2010surnames/names.zip
# Canada given names: Statistics Canada, top 10 for 2024 and 2025,
# plus the top-100 names that gained the most rank from 2023 to 2024.
# https://www150.statcan.gc.ca/n1/pub/11-627-m/11-627-m2025045-eng.htm
# https://www150.statcan.gc.ca/n1/daily-quotidien/260923/g-e001-fra.htm
# Canada 2025 top 100 given names: table 17-10-0147, rank 100 or better.
# That table stores an accented letter as the unaccented letter.
# https://www150.statcan.gc.ca/t1/tbl1/en/tv.action?pid=1710014701
# Quebec given names: Retraite Quebec, top 100 boys and top 100 girls
# by count in 2025. The downloadable bank stores LEO and EDOUARD
# with no accents, so those spellings are listed as stored.
# https://www.donneesquebec.ca/recherche/dataset/banque-de-prenoms-garcons
# https://www.donneesquebec.ca/recherche/dataset/banque-de-prenoms-filles
# The 18 June 2026 release writes Léo. French spellings of the 2025
# rows that use an accent are listed at the end of this file.
# Éloi is the French spelling of the bank row ELOI. A different
# accent, such as Éloï, Maël, Mathéo, or Océane, is not that row
# and is not listed.
# https://www.retraitequebec.gouv.qc.ca/fr/communiques-de-presse/2026/prenoms-plus-populaires-nouveau-nes-et-nouveaux-retraites-rrq-2025
# Quebec surnames: Institut de la statistique du Quebec, top 100 by rank.
# The table prints the accent. The unaccented spelling is listed too
# when the letters differ.
# https://statistique.quebec.ca/fr/produit/tableau/les-1-000-premiers-noms-de-famille-selon-le-rang-quebec
